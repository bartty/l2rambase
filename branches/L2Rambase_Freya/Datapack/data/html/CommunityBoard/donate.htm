DONATIONS

Server files have 2 types of donation: Item Type: Buff&Transform Scrolls, Gracia Pets, Ride Gracia Bransolets, Hats, Circlets, Masks, Fireworks, HP&CP&Buff Potions, MyTeleport Items. Subscription Type: GlobalGateKeeper(30 Days - teleports only normal locations with nobless locations. Use only in peace zone), MerchantOfMammon(30 Days - you have acces to Blacksmith Mammon, Merchant Mammon and can exchange Seal Stones) AioBuffer(30 Days - you can use normal buffs or with double time [check configuration] only in peace zone)

Go to npc in Giran and check what type of donations are enabled All informations needed to donate are writed in server page. REMEMBER: Not all donate options supported by server files are enabled.
